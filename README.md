## ✨ About

This is the source code for my personal website: a place for my projects, writing, and everything else I want to share. It's fast, responsive, and designed to feel good to browse on any device.

- 🎨 **Clean, modern design** with smooth animations
- 🌗 **Dark and light mode** that follows your system
- 📱 **Fully responsive** from phones to ultrawide monitors
- ⚡ **Fast loading** with optimized assets
- 🔍 **SEO friendly** with proper meta tags and social previews
- ♿ **Accessible** with semantic HTML and keyboard navigation

## 📦 Run It Locally

```bash
# clone the repo
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git

# jump in
cd YOUR_REPO

# install dependencies (skip if it's plain HTML/CSS/JS)
npm install

# start the dev server
npm run dev
```

Then open **http://localhost:3000** in your browser.
