### Deploying to GitHub Pages (The Normal, Zero-Build Way)

This repository is set up so you can simply push the files to GitHub and it works immediately:

1. **Push this repo to your GitHub repository** (e.g. `github.com/MrUranium1/...`).
2. Go to **Settings** → **Pages** in your repository.
3. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or `master`)
   - **Folder**: `/ (root)`
4. Click **Save**.
5. Under **Custom domain**, ensure `mehir.is-a.dev` is entered (the `CNAME` file at the root handles this automatically).
6. That's it! GitHub Pages directly serves `index.html`. No build scripts, no Vite, no node_modules, and no blank pages.
